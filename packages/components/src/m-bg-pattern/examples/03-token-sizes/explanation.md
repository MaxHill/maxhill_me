Use `data-size="1"` through `data-size="15"` for the fixed spacing tokens, or `data-size="fluid-1"` through `data-size="fluid-10"` for responsive tokens. For example, `data-size="5"` uses `--size-5` in both directions. Resize the window to compare the fixed and fluid examples.

Both background layers use the same spacing, so the spotlight stays aligned. Omit `data-size` to keep the utility's default spacing. The existing `large` utility alias also remains supported. Pixel values such as `data-size="24px"` are not accepted.
