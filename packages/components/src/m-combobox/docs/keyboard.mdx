Full keyboard navigation following the ARIA combobox pattern.

| Key | Action |
|-----|--------|
| Arrow Down | Move focus to next option (opens popover) |
| Arrow Up | Move focus to previous option (opens popover) |
| Ctrl+N | Next option (Emacs-style) |
| Ctrl+P | Previous option (Emacs-style) |
| Home | Jump to first option |
| End | Jump to last option |
| Enter | Select focused option |
| Space | Select focused option |
| Escape | Close popover and reset filter |
| Shift+Arrow Down | Extend selection downward (multiple mode) |
| Shift+Arrow Up | Extend selection upward (multiple mode) |
| Shift+Home | Select from current to first (multiple mode) |
| Shift+End | Select from current to last (multiple mode) |
