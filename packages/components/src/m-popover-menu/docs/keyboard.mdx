| Key | Action |
|-----|--------|
| Enter / Space | Open menu from trigger; activate focused item |
| Escape | Close the menu and return focus to trigger |
| ArrowDown | Move focus to next menu item |
| ArrowUp | Move focus to previous menu item |
| Home | Move focus to first menu item |
| End | Move focus to last menu item |
| Tab | Close menu and move focus out |
