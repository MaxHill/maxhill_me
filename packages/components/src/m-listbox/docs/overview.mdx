`m-listbox` provides single or multiple selection from a list of options with three distinct selection modes. It supports full keyboard navigation, form integration, and follows the ARIA listbox pattern for accessibility.

The component supports three modes: `single-select` (default - arrow keys move selection), `single-focus` (arrow keys move focus, Space/Enter selects), and `multiple` (multi-selection with toggle).

<CodeExample html={`<m-listbox name="fruit">
  <m-option value="apple">Apple</m-option>
  <m-option value="pear">Pear</m-option>
  <m-option value="orange">Orange</m-option>
  <m-option value="banana">Banana</m-option>
</m-listbox>`} />
