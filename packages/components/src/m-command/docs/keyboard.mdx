Commands are triggered via configurable keyboard shortcuts using the `keys` attribute syntax.

| Key | Action |
|-----|--------|
| User-defined shortcut | Triggers the bound command (navigate, show-modal, close, focus, etc.) |
| Escape | Close dialog/popover opened by a command |

The `keys` attribute uses the format `<C-b>x` where `C` is Ctrl/Cmd, followed by a sequence key. Multiple key sequences can be chained.
